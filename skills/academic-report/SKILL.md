# Academic Report

## Progressive loading
1. Use the core evidence rules below.
2. For data-heavy work, read `references/evidence-ledger.md`.
3. Before drafting sections, read `references/section-playbook.md`.
4. For citations, read `references/citation-integrity.md`.
5. For interpretation and discussion, read `references/uncertainty-and-causality.md`.

## Core rules
- Write from evidence outward; do not draft a conclusion and retrofit support.
- Distinguish user-provided facts, observations, calculations, sources, interpretations, and assumptions.
- Do not invent missing parameters, samples, instruments, repetitions, error bars, significance, or experimental outcomes.
- Preserve anomalies and limitations instead of smoothing them away.
- Match claim strength to evidence.
- Use real citations and never manufacture bibliographic details.
- Keep technical precision; “humanizing” must not remove domain-specific meaning.
- Follow the assignment's required structure instead of forcing a generic paper template.
