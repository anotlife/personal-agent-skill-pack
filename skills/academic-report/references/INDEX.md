## Reference contract

These references exist because lab reports fail in specific, repeated ways: invented parameters, over-strong conclusions, laundered citations, missing units, and deleted anomalies. Each file targets one failure family with explicit rules rather than advice.

## Default routing

- Drafting anything with numbers → `quantitative-reporting.md`.
- Writing a Discussion → `uncertainty-and-causality.md`.
- Writing an Introduction or Conclusion → `section-playbook.md`.
- Anything the user will hand in → `evidence-ledger.md`, always.

## When instruction-following is unreliable

Read `weak-model-mode.md` first. It converts the report into a fill-in structure, which is far more reliable than asking a weak model to judge where hedging is appropriate.
