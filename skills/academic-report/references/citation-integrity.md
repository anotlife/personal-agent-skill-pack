# Citation Integrity

## Source rules

Prefer the original paper, standard, official documentation, or original dataset over anything that describes it. Cite the source closest to the fact.

Read what you cite. A citation is a claim that you saw the supporting material, not that you found a title.

## Never invent

Do not guess or reconstruct:

- DOI, PMID, arXiv id, ISBN;
- journal, volume, issue, or page numbers;
- author list or author order;
- publication year;
- an exact quotation;
- an experimental detail the source does not contain.

If you are unsure of any field, leave the citation out and cite something you verified instead. A fabricated reference survives until someone checks it, and then it destroys the credibility of everything beside it.

## Citation scope

One citation supports the specific statement immediately before it.

- A paragraph containing three claims from three sources needs three citations, not one at the end.
- A source cited for a broader claim than it makes is citation laundering. Narrow the claim or widen the evidence.
- A review article supports "reviews report X", not "the original study found X" — cite the original study for that.
- A paper's Discussion section is the authors' interpretation, not a measured result. Cite it as an interpretation.
- If the source says "may", "suggests", or "is consistent with", the report must not say "shows" or "proves".

## Literature synthesis, not a list

A list of paper summaries is not a literature review. The synthesis must:

1. group sources by what they claim, not by publication order;
2. compare **methods** — how each arrived at its result;
3. compare **outcomes** — where they agree and where they diverge;
4. compare **limitations** — what each design could not show;
5. identify the specific open question the present work addresses.

The most valuable sentence in a literature review names a **contradiction** between sources and explains what would resolve it.

## Citing your own work

- Distinguish your own result from a cited result, in the text, not just by the citation.
- When your result contradicts a cited source, say so plainly. That is a finding.

## Common failures

| Failure | Correction |
|---|---|
| Citation at paragraph end covering four claims | One citation per claim |
| "Studies show" with no specific citation | Name the studies, or drop the claim |
| Textbook cited for a specific recent number | Cite the primary source |
| Secondary source cited for an original finding | Cite the original |
| Author/year invented to satisfy a format | Leave the field out; find the real reference |
| Source that supports part of the sentence only | Narrow the sentence |
| A quote not in the source | Remove it, or find the exact wording |

## Format consistency

Follow the required style (APA, IEEE, ACM, or the instructor's spec) exactly — including how multiple authors, et al., page ranges, and DOIs are written. Inconsistent formatting is the first thing a marker notices, and it undermines confidence in the numbers.

If the assignment specifies a citation style, it outranks any default. If a reference manager is used, export rather than typing entries.

## Checklist

- [ ] Every citation sits beside the claim it supports.
- [ ] Every citation's scope matches the claim's scope.
- [ ] No metadata field was written from memory.
- [ ] The literature section compares methods and limitations, not just findings.
- [ ] Formatting follows the required style consistently.
