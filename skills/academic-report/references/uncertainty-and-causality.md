# Uncertainty and Causality

## Claim ladder

Use the strongest statement the evidence permits:

- **observed:** “X increased from A to B in the recorded run.”
- **supported interpretation:** “The result is consistent with X contributing to Y.”
- **tentative explanation:** “One possible explanation is …”
- **causal claim:** reserve for designs that actually identify causality.

## Watch for

- correlation → causation;
- one run → general rule;
- small sample → population claim;
- expected mechanism → demonstrated mechanism;
- missing controls → strong attribution;
- statistical significance → practical significance.

## Discussion discipline

For a surprising result, preserve the surprise. Give plausible explanations and identify what extra measurement or experiment would discriminate between them.
