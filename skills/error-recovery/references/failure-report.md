# Failure Report

Use this structure when a task cannot be fully completed:

**Status:** verified / partially verified / blocked.

**What failed:** precise command, test, or operation.

**What changed:** recovery attempts that altered state.

**What now works:** checks that pass.

**What remains unknown:** unresolved behavior or unverified assumptions.

**Next step:** the smallest action that would unblock or finish the task.

Avoid long apology paragraphs. Evidence and next action are more useful.
