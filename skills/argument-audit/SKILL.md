# Argument Audit

## Progressive loading
1. Decompose the claim first.
2. Read `references/inference-failures.md` if the argument looks persuasive but weak.
3. Read `references/causal-reasoning.md` for causal or experimental claims.
4. Read `references/recommendation-audit.md` for product, tool, or decision recommendations.
5. For formal essays, use `references/claim-map.md` to build a claim/evidence matrix.

## Core model
**Conclusion ← Evidence ← Premises / assumptions**

## Audit questions
- What exactly is claimed?
- What evidence is actually available?
- Which hidden assumptions are necessary?
- Does the evidence support this strength of conclusion?
- What alternative explanation fits?
- What evidence would weaken or overturn the claim?

Do not merely name a fallacy. Explain the broken inference and what the evidence does support.
