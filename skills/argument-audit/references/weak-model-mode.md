# Weak-Model / Low-Attention Mode

Weak models produce lists of fallacy names instead of audits, and they break the rule that matters most: state what the evidence *does* support.

## The four questions per claim

For every conclusion in the argument, answer these four in order. Do not label anything until all four are answered.

1. **What exactly is claimed?** Write it as one sentence.
2. **What does the evidence directly show?** Write it as one sentence, using only what the argument presents.
3. **What is the gap between (2) and (1)?** Name it concretely — a missing control, a different population, a shifted term, a third variable.
4. **What is the strongest version of the claim that (2) supports?** Write that sentence.

Question 4 is mandatory. An audit without it is a demolition, not an analysis.

## Hard rules

- Never write a fallacy name without writing the concrete gap.
- Never attack a weaker version of the argument than the author made.
- Never say an argument is "wrong" when it is underdetermined. Say what it does and does not establish.
- Never treat disagreement about values as an error of logic.
- Never apply a check to the argument that you have not applied to your own conclusion.

## The three checks every causal claim must pass

1. What else changed at the same time?
2. What is the comparison or control?
3. Could the effect run the other way?

If any answer is "nothing / none / no", the causal claim is unsupported. Write: "The evidence shows X and Y changed together; it does not isolate X's effect because Z also changed."

## The three checks every recommendation must pass

1. What criteria are being used, and who chose them?
2. What is the trade-off — what gets worse?
3. What would make the recommendation wrong?

If the criteria are unstated, say "assuming you care most about A and B".

## Banned output shapes

- A list of fallacy names with no repair.
- "This is a logical fallacy" with no explanation.
- "Both sides have valid points" with no analysis.
- Three paragraphs of summary followed by one line of audit. Reverse the proportion.
- A verdict with no stated scope.

## Final gate

- [ ] Every claim got all four questions answered.
- [ ] Every causal claim passed the three checks.
- [ ] Every recommendation got its criteria and trade-off named.
- [ ] I wrote the narrowed, supportable version of each claim.
- [ ] I applied the same checks to my own conclusion, and said so if it failed.
