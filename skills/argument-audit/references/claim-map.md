# Claim Map

For each important conclusion, write:

**Claim:** what exactly is being asserted?

**Evidence:** what observation, source, measurement, or example supports it?

**Bridge:** what reasoning connects evidence to claim?

**Assumptions:** what must be true for the bridge to hold?

**Scope:** where does the claim apply, and where does it not?

**Falsifier:** what new evidence would make the claim weaker?

This prevents “evidence pile → unsupported conclusion” reasoning.

For long arguments, store one row per important claim rather than auditing every sentence equally.
