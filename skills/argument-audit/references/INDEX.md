# Argument Audit — Reference Index

| Situation | Read |
|---|---|
| Argument longer than a paragraph; need a structured audit | `claim-map.md` |
| Argument is persuasive but weak; need to find the breakage | `inference-failures.md` |
| Causal, experimental, before/after, or correlational claim | `causal-reasoning.md` |
| Recommendation, comparison, or decision to evaluate | `recommendation-audit.md` |
| Model is weak, distracted, or stops at naming a fallacy | `weak-model-mode.md` |

## Reference contract

`inference-failures.md` is a checklist to run, not a vocabulary to deploy. Naming a fallacy is not an audit; each entry in that file ends with what to say *instead*.

## Default routing

- Any "X causes Y" → `causal-reasoning.md`.
- Any "you should use Z" → `recommendation-audit.md`.
- Any essay, report, or paper conclusion → `claim-map.md` first.
- Any argument that feels strong and you cannot say why → `inference-failures.md`.

## When instruction-following is unreliable

Read `weak-model-mode.md` first. It converts the audit into four questions per claim, because a weak model given the full catalogue tends to produce a list of fallacy names and no analysis.
