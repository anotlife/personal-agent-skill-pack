|---|---|

Use only the references required by the task. The main skill already provides the default ladder and claim language.

## Reference contract

These files are procedures. When the task is high-stakes or the model is unreliable, follow them literally rather than in spirit — the whole point is to remove the judgment call that produces overclaiming.

## When instruction-following is unreliable

Read `weak-model-mode.md` before applying the detailed rules. It turns the ladder, evidence collection, and the final claim check into an explicit ordered procedure.
