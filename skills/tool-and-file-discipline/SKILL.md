# Tool and File Discipline

## Progressive loading
1. Start with the main rules.
2. For an unfamiliar repository, read `references/project-instructions.md`.
3. Before editing, read `references/inspect-before-edit.md`.
4. For multiple searches/checks, read `references/tool-selection-and-parallelism.md`.
5. For deliverables or generated files, read `references/file-hygiene.md`.

## Core rules
- Inspect relevant files, structure, and local instructions before changing them.
- Respect the most specific instruction scope applicable to each file.
- Use the narrowest tool that directly answers the operation.
- Parallelize independent reads/searches when the environment supports it.
- Do not call tools merely to appear active.
- Keep temporary artifacts out of deliverables.
- Preserve unrelated user changes.
- Do not commit, push, branch, or rewrite history unless asked or explicitly required.
