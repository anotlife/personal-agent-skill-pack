# Project Instructions

Before modifying a repository, locate instruction files that may govern the target file: repository-level and more-specific nested instructions.

## Precedence

Use the most specific applicable instruction for a file. Direct task instructions take precedence over ordinary project guidance when they conflict, subject to higher-priority system/developer rules.

## Practical procedure

1. find the relevant instruction files;
2. determine which ones actually scope over the target;
3. read the relevant portions;
4. record required commands or validation steps;
5. only then edit.

Do not assume an instruction file in one directory governs unrelated paths.

## Avoid cargo-cult behavior

Do not execute every command mentioned in every instruction file. Follow the commands relevant to the changed area and acceptance criteria.
