## Reference contract

The two references that decide outcomes are `briefing-a-delegate.md` (a brief without a retrieval step is the difference between a usable artifact and a confident wrong one) and `verifying-delegates.md` (a delegate's report is a claim, not a result).

## Default routing

- Before launching anything → `when-to-delegate.md`.
- Before writing the prompt → `briefing-a-delegate.md`.
- After the result arrives → `verifying-delegates.md`, always.
- Two or more concurrent writers → `parallel-and-isolation.md`.

## When instruction-following is unreliable

Read `weak-model-mode.md` first. It provides a fixed brief template and a mandatory post-return check, because a weak model delegated to by a weak model is where silent wrongness accumulates fastest.
