# Review and Critique — Reference Index

| Situation | Read |
|---|---|
| Reviewing code, a diff, a plan, or a document | `review-mindset.md` |
| About to report your own work complete | `self-review.md` |
| Corrected, contradicted, or asked to defend a position | `receiving-critique.md` |
| Model is weak, distracted, or reviews superficially | `weak-model-mode.md` |

## Reference contract

`self-review.md` is the highest-value file here, because you review your own work far more often than anyone else's. It contains the checks that distinguish "I did the thing" from "the thing works".

## Default routing

- Any review request → `review-mindset.md`.
- Any completion claim of your own → `self-review.md`.
- Any correction or disagreement → `receiving-critique.md`.

## When instruction-following is unreliable

Read `weak-model-mode.md` first. It enforces a findings-first output shape with a location on every finding, which is the structure a weak model most often abandons in favour of a reassuring summary.
