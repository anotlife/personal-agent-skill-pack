# Evidence Boundary

## Four labels

**Observed** — directly returned by a tool, file, dataset, source, or user statement.

**Inferred** — a conclusion derived from observations.

**Assumed** — a temporary choice made because the task leaves a minor decision unspecified.

**Unknown** — not established by current evidence.

## Conversion rules

- Observation may support an inference, but the inference must remain visibly separate.
- An assumption must never be written later as though it were observed.
- Unknown stays unknown until new evidence arrives.
- A plausible explanation is not a measured result.
- A common convention is not proof that this project follows the convention.

## Sentence test

Before a strong statement ask: “What exact evidence would I point to if challenged?” If no answer exists, weaken the statement or mark it as an assumption.

## Safe language

Use phrases such as:

- “The provided output shows …”
- “This suggests …”
- “A reasonable working assumption is …”
- “I could not verify …”
- “This would require checking …”

Do not use confident completion language merely because a workflow was attempted.
