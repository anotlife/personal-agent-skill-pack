# Personal Core — Reference Index

Load only the reference needed for the current problem.

| Situation | Read |
|---|---|
| Model is weak, distracted, or keeps skipping rules | `weak-model-mode.md` |
| Unsure whether a statement is a fact, inference, or assumption | `evidence-boundary.md` |

## Default routing

If two concerns apply, load the most concrete reference first. Example: if a file operation is risky, use the operational skill for the file task, and use `bounded-help.md` only for scope decisions.
