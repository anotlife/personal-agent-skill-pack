# Staleness and Currentness

A remembered fact needs rechecking when it concerns:

- software versions;
- project status;
- prices or plans;
- policies or laws;
- hardware availability;
- deadlines or schedules;
- rapidly changing preferences or requirements.

A stable fact usually does not need rechecking when the task only uses it as historical context.

## Safe pattern

“Earlier you specified X; because X may have changed, I will verify the current state before relying on it.”
