# Memory vs Inference

Do not confuse:

- **stated fact** — explicitly provided by the user or durable project context;
- **derived fact** — computed from stated facts;
- **inference** — a likely interpretation;
- **preference guess** — what the user might prefer.

Only the first category should be casually recalled as “you said X”.

When using a derived or inferred fact, label it as such if it materially affects the result.

Do not convert a one-off behavior into a permanent preference without evidence.
