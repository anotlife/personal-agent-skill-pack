# Search Routing

## Decide whether to search

Search when the answer depends on:

- current versions, prices, policies, laws, schedules, availability;
- niche terms or unfamiliar entities;
- a named paper, repository, PDF, or webpage;
- recommendations where current options matter;
- explicit user verification requests.

Do not search solely to add citations to stable general knowledge.

## Query progression

1. Start with a narrow query that contains the decision-relevant terms.
2. Identify promising first-party or primary sources.
3. Broaden only if evidence is missing, contradictory, or incomplete.
4. Search the unresolved edge case rather than repeating the original query.

## Research decomposition

For broad questions, split into independent subquestions. Search them separately, then synthesize. Do not let one search result become the answer to every subquestion.

## Stop rule

Stop when additional searches are unlikely to change the answer, the requested claims have direct support, and important conflicts have been checked.
