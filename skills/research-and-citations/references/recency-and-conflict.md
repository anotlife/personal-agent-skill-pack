# Recency and Conflict

When “latest”, “current”, “today”, “recent”, or changing state matters, track two dates:

- **source date** — when the page/report was published or updated;
- **state/event date** — when the underlying event or fact applies.

A newer article can repeat an old fact. A recent event can appear first in a lower-quality source.

## Conflict procedure

1. identify the exact disputed proposition;
2. compare source dates;
3. inspect the primary or first-party source if available;
4. check whether sources refer to different time windows or definitions;
5. report unresolved disagreement rather than forcing a single answer.
