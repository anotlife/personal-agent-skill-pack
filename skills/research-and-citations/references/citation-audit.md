# Citation Audit

## The five questions

For every consequential externally sourced statement:

1. What **exact claim** am I making?
2. Which source supports **that exact claim**?
3. Does the source support the whole claim, or only part of it?
4. Is the citation **close enough** for the reader to map claim to evidence?
5. Did I add an **inference** as though it came from the source?

If any answer is weak, either narrow the claim to what the source supports, or find a source that supports the full claim.

## Placement

- Put the citation **immediately after the sentence or clause** it supports. A single citation at the end of a paragraph that covers four unrelated sentences implicitly claims support for all four.
- In a table, cite inside the relevant cell rather than adding a citation column.
- Do not accumulate a trailing reference list and expect the reader to reverse-engineer the mapping.
- Do not cite the same source for claims it does not make, just because it is topically adjacent.

## Common failures

| Failure | Shape | Fix |
|---|---|---|
| **Citation laundering** | Source cited for a broader claim than it supports | Narrow the claim to the source's actual scope |
| **Stale citation** | Old evidence presented as current | Check the date; re-search if it matters |
| **Source mismatch** | Secondary summary cited when primary exists | Cite the primary; read it first |
| **Invented metadata** | DOI, author, year, page, or URL guessed from memory | Never write citation metadata you did not see |
| **Citation drift** | One citation appears to support several unrelated sentences | One claim, one citation |
| **Ghost citation** | A source referenced but never opened | Open it, or delete the claim |
| **Authority inflation** | A blog post cited as "research shows" | Name the actual source and its nature |
| **Number without provenance** | A figure with no source, or a source that gives a different figure | Quote the source's figure, or drop it |

## Never fabricate

Do not write, from memory or by pattern:

- a DOI, PMID, arXiv id, or ISBN;
- an author list, year, journal, volume, or page range;
- a URL you have not seen in tool output;
- a quotation, even a plausible-sounding short one;
- a title or headline.

A fabricated citation is the most damaging possible error in research work, because it is indistinguishable from a real one until someone checks.

If you are unsure of a source for a statement, omit the source rather than inventing an attribution. It is better to write "the mechanism is commonly attributed to X, though I could not confirm the original source" than to produce a fake reference.

## Internal claim-to-source table

For research-heavy answers, build a small table before writing prose. It does not need to be shown to the user.

| Claim | Source | Supports fully / partly | Date |
|---|---|---|---|

If a claim has no row, it has no source. Either find one or mark the claim as your own inference.

## Quotation discipline

- Quotations are short, attributed, and rare.
- Never reconstruct a passage from memory and present it as a quote.
- When you paraphrase closely, it is still a quote-shaped claim — cite it.
- See `copyright-and-quoting.md` for length limits.

## Checklist

- [ ] Every claim maps to a source at the same scope.
- [ ] Every citation sits next to the claim it supports.
- [ ] No citation metadata was written from memory.
- [ ] No source is cited that I did not open.
- [ ] No inference is presented as sourced fact.
- [ ] Numbers carry their source, denominator, and unit.
