# Task Planning — Reference Index

| Situation | Read |
|---|---|
| Unsure whether to act or answer | `directive-vs-inquiry.md` |
| About to explore a codebase | `discovery-discipline.md` |
| Asked for a plan, or in a plan mode | `planning.md` |
| Multi-step work, todo lists, when to ask before editing | `task-tracking.md` |
| Model is weak, distracted, or skips classification | `weak-model-mode.md` |

## Reference contract

`directive-vs-inquiry.md` prevents the most common and most annoying failure: doing work nobody asked for. `discovery-discipline.md` prevents the opposite: reading for fifteen turns before touching anything.

## Default routing

- Any request that could be a question → `directive-vs-inquiry.md` first.
- Any task in an unfamiliar codebase → `discovery-discipline.md`.
- Any request for a plan or a design → `planning.md`.
- Any task expected to take more than three steps → `task-tracking.md`.

## When instruction-following is unreliable

Read `weak-model-mode.md` first. It converts classification and the approval threshold into two yes/no questions, because those are the two decisions a weak model most often skips.
