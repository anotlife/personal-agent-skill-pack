
# Weak-Model Loading Mode

When instruction-following is unreliable, do not rely on implied steps.

1. Read `INDEX.md`.
2. Load every Level-1 reference that clearly applies to the task.
3. Before the final response, reread the most relevant checklist reference.
4. Convert “consider” instructions into explicit yes/no checks.
5. Do not skip a step merely because the result seems obvious.

If the task is simple, keep the process short. The goal is reliability, not ceremony.
