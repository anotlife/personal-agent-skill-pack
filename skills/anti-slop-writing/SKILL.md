# Anti-Slop Writing

## Progressive loading

1. Apply the compact principles below.
2. Read `references/slop-patterns.md` when the draft has obvious AI-like habits.
3. Read `references/rewrite-method.md` when performing a substantial rewrite.
4. Read `references/formatting-and-structure.md` when the shape of the document — headings, lists, paragraphs, length — is part of the problem.
5. Read `references/academic-register.md` for coursework, reports, or technical writing.
6. Read `references/voice-and-specificity.md` when the goal is a natural personal style.
7. Weak model: read `references/weak-model-mode.md` first.

## Core rules

- **Remove low-information language, not merely suspicious vocabulary.** The target is sentences that carry no claim, no evidence, and no reasoning — not a list of banned words.
- **Do not inflate** significance, certainty, novelty, or scope.
- **Prefer concrete nouns, verbs, numbers, examples, and named relationships** over abstract containers like "aspects", "factors", "considerations", "dynamics", "landscape".
- **Do not manufacture rhetorical structure.** No invented contrasts, no forced triads, no headings added for symmetry, no conclusions written to close a shape.
- **Preserve facts, citations, uncertainty, technical terminology, and the requested structure.** A rewrite that changes any of these is a defect, not an improvement.
- **Vary sentence and paragraph length naturally** — which means according to content, not according to a formula for variation.
- **"Humanizing" never means adding** fake personal experience, invented anecdotes, new evidence, or stylistic quirks the writer did not have.
- **Do not chase AI detectors.** Optimising for a detector produces a different, equally artificial style, and the honest goal — specific, information-dense prose — is the same one a detector is a poor proxy for.

## The one-sentence test

If a sentence can be deleted without losing information, reasoning, evidence, or a necessary transition, delete it.

Apply it in this order: paragraphs first, then sentences, then clauses. Most slop is not bad sentences — it is sentences that should not exist.

## Second test: the specificity test

For each remaining sentence, ask: *could this sentence appear in a document about a different topic?*

If yes, it carries no information about this one. "This approach offers several advantages" could be in any document ever written. Replace it with the actual advantages, or delete it.

## Third test: the falsifiability test

A sentence that no possible evidence could contradict is not a claim. "Communication plays a vital role in team success" cannot be wrong, so it says nothing.

## Final gate

- No sentence survives the delete test.
- No sentence survives the specificity test, unless it is a necessary transition.
- Certainty, scope, and attribution are unchanged from the source.
- Nothing was invented: no example, number, name, citation, or experience.
- Formatting matches the document type and the user's request.
