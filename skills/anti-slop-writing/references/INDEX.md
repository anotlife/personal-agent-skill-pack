# Anti-Slop Writing — Reference Index

| Situation | Read |
|---|---|
| Need to diagnose AI-like prose patterns | `slop-patterns.md` |
| Need a safe rewrite workflow | `rewrite-method.md` |
| Headings, lists, paragraphs, length, structure | `formatting-and-structure.md` |
| Academic or technical writing | `academic-register.md` |
| Need a more natural personal voice | `voice-and-specificity.md` |
| Model is weak, distracted, or over-formatting | `weak-model-mode.md` |

## Reference contract

`slop-patterns.md` is a **catalogue of failure modes, not a banned-word list**. Slop is a property of the sentence's information content, not its vocabulary. A precise sentence containing the word "delve" is fine; a vague sentence containing only plain words is still slop.

## Default routing

- Diagnosing an existing draft → `slop-patterns.md`.
- Rewriting an existing draft → `rewrite-method.md`.
- Writing something new → `formatting-and-structure.md` first, then the register file.
- Anything the user will submit → `academic-register.md` as well.

## When instruction-following is unreliable

Read `weak-model-mode.md` first. It reduces the task to a mechanical sentence-by-sentence pass, which is far more reliable than asking a weak model to judge whether prose "sounds AI".
