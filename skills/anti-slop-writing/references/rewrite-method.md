# Rewrite Method

## The two-pass rule

Never mix preservation and improvement in one reading. The first pass establishes what must not change; the second changes everything else. Mixing them is how a rewrite silently drops a citation or softens a limitation.

## Pass 1 — preserve meaning (do not rewrite yet)

Mark, in the source text:

1. **Factual content** — every claim, value, date, name, quantity.
2. **Evidence and citations** — every source reference and what it supports.
3. **Uncertainty** — every hedge that carries information, every stated limitation.
4. **Required structure** — headings, section order, word limits, format spec.
5. **Technical terminology** — domain terms that have precise meanings.
6. **Voice markers the user supplied** — their own phrasing, register, and preferences.
7. **Sentences that must not change** — anything already correct and dense.

Write this list down. It is the contract for pass 2.

## Pass 2 — improve prose

Work in this order. Each step is independent; do not skip ahead to polishing sentences before the paragraph level is settled.

1. **Delete whole sentences** that fail the delete test.
2. **Delete whole paragraphs** that repeat another paragraph.
3. **Merge** paragraphs that make one point in two places.
4. **Reorder** so the actual argument leads.
5. **Replace abstract nouns** with concrete subjects and verbs where the content allows.
6. **Fix transitions** — name the real relationship, or delete the connector.
7. **Shorten** the remaining long sentences, one clause at a time.
8. **Vary sentence length** where the content varies in complexity — not on a pattern.
9. **Check the register** — see `academic-register.md` or `voice-and-specificity.md`.
10. **Reread for newly introduced claims.** This step is mandatory. Rewriting reliably creates claims that were not in the source.

## The forbidden shortcut

Do **not** "humanize" by fabricating:

- anecdotes or personal experience;
- opinions the writer did not state;
- sources, numbers, or examples;
- stylistic quirks invented to look idiosyncratic;
- deliberate grammatical errors.

A rewrite may only remove, reorder, and rephrase what is there.

## Preservation audit

Compare the rewrite against the pass-1 list, item by item:

| Question | If any answer is no |
|---|---|
| Does every fact survive, unchanged? | Revert that sentence |
| Does every citation still sit beside its claim? | Restore it |
| Is the confidence level identical? | Restore the original hedge |
| Are all limitations still present? | Restore them |
| Is every technical term intact? | Restore it |
| Is the required structure intact? | Restore it |
| Did I add any claim not in the source? | Delete it |

## Working patterns

**Cut first, then polish.** A 30% cut usually improves prose more than any amount of sentence-level editing. If the rewrite is the same length as the source, you have decorated it rather than edited it.

**Ask the "so what" question per paragraph.** If a paragraph's point cannot be stated in one clause, the paragraph has two points.

**When the source is factually thin, do not add filler about its thinness.** Replace padding with a statement of what is not known. "The source does not report the sample size" is better than a paragraph about the importance of sample size.

**When the source is good, change less.** Rewriting correct, dense prose is pure risk. If a sentence is already specific and accurate, leave it — including if it is formal, passive, or long.

## Register calibration

Match the register to the destination, not to a preference:

| Destination | Register |
|---|---|
| Lab report or paper | Formal, technical, passive where the process matters |
| Study notes | Compact, can be clipped and list-shaped |
| Class discussion post | Conversational, first person, shorter sentences |
| Code documentation | Imperative, direct, present tense |
| Email or message | Plain, brief, one purpose |

Do not write a lab report in blog register, and do not write a message in paper register.

## Final comparison

State, in one line, what changed: *"Cut 22% of the words, removed 6 closer sentences, restored the two hedges the draft dropped, no facts changed."*

If you cannot state it, you do not know what you did.
