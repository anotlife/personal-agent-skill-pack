# Rewrite Method

Use a two-pass method.

## Pass 1 — preserve meaning
Mark:

- factual content;
- evidence and citations;
- uncertainty;
- required structure;
- technical terminology;
- statements that must not change.

## Pass 2 — improve prose
Then:

1. remove empty framing;
2. shorten redundant sentences;
3. replace abstract nouns with concrete wording when possible;
4. fix awkward transitions;
5. vary sentence length when it reflects the content;
6. preserve the original confidence level;
7. reread for newly introduced claims.

## Forbidden shortcut
Do not “humanize” by fabricating anecdotes, personal experiences, opinions, sources, or stylistic quirks that the writer did not provide.

## Final comparison
Ask: did the rewrite change any fact, certainty, implication, or attribution? If yes, revert that part.
