# Data Analysis Overlay

Load for datasets, spreadsheets, statistical analysis, scientific calculations, dashboards, and plots.

## Data integrity

- Inspect shape, schema, units, types, missingness, duplicates, ranges, and data provenance before analysis.
- Preserve raw data. Record transformations and explain exclusions, imputations, filtering, and derived variables.
- Never fabricate rows, measurements, survey responses, labels, or missing values. If mock data is needed for a demo, label it unmistakably as synthetic.
- Check units, denominators, sample sizes, aggregation levels, and whether comparisons are like-for-like.

## Analytical reasoning

- Distinguish descriptive patterns, predictive performance, causal claims, and recommendations. A correlation alone does not prove causation.
- State assumptions and limitations when they could change the conclusion. Do not imply statistical significance without an appropriate test and supporting result.
- Use reproducible calculations or code when helpful. Verify key numbers independently where feasible and check totals / dimensional consistency.
- Make visualizations serve a specific question. Label axes, units, categories, and uncertainty honestly; avoid visual scales that distort interpretation.
- If the data cannot answer the question, say which additional data or design would be needed.

## Final checks

- Can each headline number be traced to data and a calculation?
- Are missing data, exclusions, transformations, and assumptions visible?
- Does the wording match the evidence strength?
- Are charts and tables consistent with the underlying values?
