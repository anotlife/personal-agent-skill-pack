# Distillation Matrix

This is the "why" behind the pack. Several distinct prompts often express the same underlying idea; those expressions were merged here.

| Recurring source behavior | General principle | Pack skill |
|---|---|---|
| Current/present-day facts trigger search | Time-sensitive claims need fresh evidence | `research-and-citations` |
| Primary-source preference | Evidence quality matters more than search volume | `research-and-citations` |
| Citation placement/minimization | Citations should support consequential claims cleanly | `research-and-citations` |
| Ask only when a missing detail blocks work | Avoid unnecessary clarification loops | `personal-core`, `scope-and-minimal-change` |
| Use reasonable defaults and state them | Keep momentum without hiding assumptions | `personal-core` |
| Plans for complex work, not trivial work | Planning effort should match task complexity | `scope-and-minimal-change` |
| Minimal focused patches | Limit scope and preserve repository conventions | `scope-and-minimal-change` |
| Read project rules before edits | Local instructions are part of the task environment | `tool-and-file-discipline` |
| Verify by execution | Completion is a postcondition, not an intention | `verify-before-claim` |
| Independent verification oracle | Self-consistency is not proof | `verify-before-claim` |
| Report failures faithfully | Never manufacture a green result | `verify-before-claim`, `error-recovery` |
| Retry with corrected arguments | Failure should trigger diagnosis, not repetition | `error-recovery` |
| Avoid unrelated fixes | Prevent scope explosion | `scope-and-minimal-change` |
| Avoid canned conclusions and AI vocabulary | Remove style patterns that add no information | `anti-slop-writing` |
| Avoid invented contrast and labels | Say the actual relationship directly | `anti-slop-writing` |
| Memory listing / past-chat retrieval | Check available context before asking again | `context-and-memory` |
| Store only what the user actually stated | Do not turn inference into memory | `context-and-memory` |
| Evidence-led academic prose | Claim strength must follow evidence | `academic-report` |
| Argument decomposition | Separate claim, premises, evidence, and inference | `argument-audit` |
